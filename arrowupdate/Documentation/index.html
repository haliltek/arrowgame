Requirements

To open and build this project, you will need:

  • Android Studio Koala (2024.1.1) or newer
  • JDK 17 (Recommended) or JDK 21
  • Gradle 8.5+
  • Programming Language: Java 17
  • compileSdk Version: 36
  • Minimum SDK Version (minSdk): 23
  • Target SDK Version (targetSdk): 36

Note: Google Play requires new apps to target the latest Android SDK version available at the time of publishing.

A) Import Project Into Android Studio - top

After you download the files from CodeCanyon, there is the project source code at "Android Code Source".

Follow these steps to import the project into Android Studio and Install the necessary SDK:

Step 1: Click File → New → Import Project.

Step 2: Browse to the folder named Android Code Source and select it.

Step 3: Click OK and wait for Gradle to sync.

Step 4: Install Android 16 (36 API) from SDK Manager.

B) Rename Package - top

You can rename package by follow these steps:

Step 1: In Android Studio, switch to Project view.

Step 2: Navigate to app → java → com.

Step 3: Right click on your current package name.

Step 4: Click Refactor → Rename.

Step 5: Select Rename Package and enter your new package name.

Step 6: Click Refactor and wait until the process completes.

Step 7: Open app/build.gradle and update the applicationId and namespace with the same new package name.

C) Change Game Name - top

You can change game name by follow these steps:

Step 1: Open Android Studio.

Step 2: Go to app → res → values → strings.xml.

Step 3: Edit the app_name value.

D) Change Game Icon - top

You can change game icon by follow these steps:

Step 1: Prepare your new icon in PNG format.

Step 2: Go to app → res → mipmap folder.

Step 3: Replace the existing ic_launcher and ic_launcher_round files with your new icons.

Step 4: Make sure you replace icons in all density folders (mdpi, hdpi, xhdpi, xxhdpi, xxxhdpi).

Step 5: Clean and rebuild the project.

If you want to know about screen densities and icon dimensions, please take a look at below.

H) Change AdMob Ads - top

Step 1: Open AndroidManifest.xml.

Step 2: Locate the AdMob App ID.

Step 3: Replace it with your own AdMob App ID from AdMob dashboard.

Step 4: Go to MainActivity.java.

Step 5: Scroll to the Interstitial Ad section.

Step 6: Replace the existing Ad Unit ID with your own Interstitial Ad Unit ID.

Step 7: Open app → res → layout → activity_main.xml.

Step 8: Scroll to the Banner Ad section.

Step 9: Replace the Banner Ad Unit ID with your own Ad Unit ID.

Step 10: Go to MainActivity.java.

Step 11: Scroll to the Rewarded Ad section.

Step 12: Replace the existing Ad Unit ID with your own Rewarded Ad Unit ID.

Step 13: Rebuild the project.

I) Generate Signed APK / AAB - top

Before publishing your app on Google Play, you must generate a signed release file. You can generate either:

  • Android App Bundle (.aab) – Recommended for Google Play
  • Signed APK (.apk) – For manual distribution or testing

Step 1: Generate a Keystore File

  1. Open the project in Android Studio.
  2. Click Build → Generate Signed Bundle / APK.
  3. Choose Android App Bundle or APK, then click Next.
  4. Click Create new... to create a new keystore.
  5. Choose a safe location on your computer.
  6. Fill in the required information:
    • Keystore password
    • Key alias
    • Key password
    • Validity (Recommended: 25 years or more)

⚠ Important: Keep your keystore file safe. If you lose it, you will NOT be able to update your app on Google Play.

Step 2: Generate Android App Bundle (.aab) – Recommended

  1. Go to Build → Generate Signed Bundle / APK.
  2. Select Android App Bundle.
  3. Choose your created keystore.
  4. Select release build variant.
  5. Click Finish.

After build completes, your AAB file will be located in:

app/release/app-release.aab

Upload this file directly to Google Play Console.

Step 3: Generate Signed APK (.apk)

  1. Go to Build → Generate Signed Bundle / APK.
  2. Select APK.
  3. Choose your keystore.
  4. Select release build variant.
  5. Click Finish.

After build completes, your APK file will be located in:

app/release/app-release.apk

You can use this APK for:

  • Manual installation
  • Testing on devices
  • Uploading to third-party app stores

J) Troubleshooting - top

Gradle Sync Failed:

- Click File → Sync Project with Gradle Files

- Make sure SDK version is installed

Ads Not Showing:

- Check AdMob App ID

- Make sure test ads are removed

- Check internet connection

Build Failed:

- Clean project (Build → Clean Project)

- Make sure compileSdk matches installed SDK
